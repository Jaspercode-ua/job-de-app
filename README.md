# job-de-app — список вакансий швеи (мини-приложение Telegram)

Страница со всеми найденными вакансиями швеи в Нюрнберге и в радиусе ~30 км. Открывается из бота кнопкой «Вакансии» и по прямой ссылке.

- `index.html` — сама страница (без сборки и зависимостей, подстраивается под тему Telegram).
- `jobs.json` — список вакансий. Его каждое утро обновляет ежедневная задача Claude.

Публикуется через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

Здесь только публичные данные из объявлений: без подписчиков бота и без заметок семьи.
